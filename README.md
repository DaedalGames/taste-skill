# scene-media

Pictures, footage and frame sequences for the scroll-scene demo pages of
[taste-skill](https://github.com/Leonxlnx/taste-skill) (`skills/taste-skill/assets/scenes/demo/`).

They live on this separate branch so the skill itself stays text: the demos load them from jsDelivr,
from this branch (`https://cdn.jsdelivr.net/gh/Leonxlnx/taste-skill@scene-media/<scene>/<file>`).
Nothing here is part of the skill an agent installs.
